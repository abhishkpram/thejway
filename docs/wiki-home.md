# Thejway | College bus tracking

This wiki records the requirements, source material, and current implementation for Thejway's college bus-tracking MVP. The Phase 1 baseline is derived from the requirements email and its Malayalam discussion transcript. The frontend is a synthetic browser demo, not a production service.

## Start here

- [Phase 1 requirements](Requirements) — roles, scope, deferred features, open decisions, and conflicts with mockups.
- [Architecture and setup](Architecture-and-Setup) — demo boundaries, run instructions, and production integration decisions.
- [Source materials](Source-Materials) — email prototypes, preview, and provenance.
- [Discussion transcript](Discussion-Transcript) — supplied English translation summary and Malayalam transcript.

## Current state

The demo exercises student/faculty absence marking, driver stop status, and admin bus assignment. It has no real authentication, backend, persistence, Maps integration, or GPS feed. Fees and payments are Phase 2.

The source repository is [abhishkpram/thejway](https://github.com/abhishkpram/thejway). Future agents should read its [AGENTS.md](https://github.com/abhishkpram/thejway/blob/main/AGENTS.md) before changing the app.
