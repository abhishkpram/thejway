These are frontend prototypes, not verified integrations. In particular, authentication, attendance persistence, live GPS data, payments, and other backend behavior remain unverified. Some pages contain inline JavaScript and reference external font and Tailwind CDN resources. They are preserved as source artifacts, are not used by the demo, and have not been loaded or executed as part of the app.
